# Orchestrator Agent — Releases

Hier liegen **ausschließlich die gebauten Binaries** von Orchestrator Agent: die
signierten und notarisierten `.dmg`-Dateien für macOS sowie die `latest-mac.yml`, aus der
die App ihre automatische Aktualisierung bezieht.

**Der Quellcode liegt nicht hier und bleibt privat.** Dieses Repo ist nur deshalb
öffentlich, weil `electron-updater` die Release-Dateien ohne Zugangsdaten lesen muss.

## Installieren

Unter [Releases](../../releases) das neueste `.dmg` herunterladen, öffnen und
„Orchestrator Agent" in den Programme-Ordner ziehen. Danach hält sich die App selbst
aktuell: sie lädt neue Versionen im Hintergrund und spielt sie beim nächsten Beenden ein.
